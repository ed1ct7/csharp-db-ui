# Database UI — WPF + SQLite (lab 1)

First college database lab: a WPF application that displays and edits data in
a SQLite database.

## Structure

- `04,01 First/` — WPF project (main window)
- `Simple_dataBase_UI Individual/` — the individual task variant
- `task/` — task documents (Russian)
- `testdb.sqlite` — the sample database

Open `04,01 First.sln` in Visual Studio and run.
